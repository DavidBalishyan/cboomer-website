# cboomer website

Website for [cboomer](https://github.com/DavidBalishyan/cboomer), a fullscreen screenshot viewer for Linux.

## Stack

Qwik (CSR), Tailwind CSS v4, Vite, TypeScript, pnpm.

## Development

```bash
pnpm install
pnpm dev
```

Runs at http://localhost:5173.

## Build

```bash
pnpm build
```

Output goes to `dist/`. To build with a base path (for GitHub Pages):

```bash
pnpm build
```
